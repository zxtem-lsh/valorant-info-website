# Valorant Info Website

University web project built with HTML, CSS and JavaScript.

The website contains several pages and uses separate style sheets and JavaScript files for layout and interactive behavior.

## Pages

- `index.html`
- `pages/history.html`
- `pages/schedule.html`
- `pages/slides.html`

## JavaScript

- `js/script.js`
- `js/slider.js`

The included scripts provide interactive page behavior, including a slider and other interface interactions.

## Styles

- `css/history.css`
- `css/main.css`
- `css/schedule.css`
- `css/slider.css`

## Technologies

- HTML
- CSS
- JavaScript
- Responsive web layout

## Project context

This repository is a cleaned public version of a university web project. Editor, system and unrelated submission files are excluded.
